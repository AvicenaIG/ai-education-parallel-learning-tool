# ai-education-parallel-learning-tool.Runner

`ai-education-parallel-learning-tool.Runner` is an alias of [`AsyncRunner`][ai-education-parallel-learning-tool.runner.AsyncRunner],
the runner that evaluates the learner's function in the background of a Jupyter
notebook or any other running asyncio event loop.
Use [`BlockingRunner`][ai-education-parallel-learning-tool.runner.BlockingRunner] to run from a script without an event loop.

::: ai-education-parallel-learning-tool.Runner
